## How to Run the Projects

1. Open the folder for the desired week in a terminal.
2. Compile the Java source file(s):

```bash
javac <FileName>.java
```

3. Run the compiled main class:

```bash
java <MainClassName>
```

4. For projects with multiple source files, compile all related files or use a wildcard:

```bash
javac *.java
java Main
```
