# Object-Oriented Programming Fundamentals in Java

This repository consolidates the completed Java tutorial work for the OOP fundamentals subject. It is organized in a clear weekly order for easy navigation.

## Repository structure

- `README.md`
- `SELF_REFLECTIVE_REPORT.md`
- `week1/`
- `week2/`
- `week3-4/`
- `week5/`
- `week6/`
- `week7/`
- `week8-9/`
- `week10/`

## How to use

Open the folder for the week you want to run. Each folder contains Java source files for that week's tutorial. Compile and run the main class from that week with:

```bash
javac <FileName>.java
java <MainClassName>
```
